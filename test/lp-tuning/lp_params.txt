# LP relaxation parameter settings — extended set
# Format: tag|cbc_params
#
# Sources:
#   - lp_params.txt (original 24 configs — all retained here)
#   - New additions targeting hard/unsolved instances:
#       [2] Partial pricing:      cheaper pivot for very wide problems (many columns)
#       [3] Higher idiot crash:   200–500 iterations for very large set-packing/covering
#       [4] Scaling variants:     equilibrium / geometric / off, combined with best pivots
#       [5] Row perturbation:     pertValue 70–91 also perturbs row costs (never tried)
#              pertValue 55 = maximumFraction 1e-6  (moderate; gap between 52 and 61)
#              pertValue 58 = maximumFraction 1e-3  (aggressive but below pertv61=1.0)
#              pertValue 72 = row costs + 1e-9      (like pertv52 but adds rows)
#              pertValue 75 = row costs + 1e-6      (row + moderate)
#              pertValue 81 = row costs + 1.0       (row + maximum)
#       [6] PE Dantzig / PE Steepest for both primal and dual sides
#
# NOTE: tags introduced here that use new pivot/scaling suffixes require extending
# parseLpParamTag() in CbcSolver.cpp before they can be used in -lpMethod=auto.
# The model should be retrained after selecting the best new configs from experiments.
#
# CBC default behavior: fastPreProcess milpbt (on), timeMode elapsed
# The script adds: -randomSeed, -sec, -initialSolve, output actions

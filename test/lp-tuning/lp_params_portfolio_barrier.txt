# LP relaxation parameter settings — recommended portfolio, racing, and barrier methods
# Format: tag|cbc_params
#
# Contains:
#   1) Portfolio recommendation classes (-lpMethod recommend / CbcLpParamScorer):
#      - dual_default: baseline dual simplex
#      - dual_pertv58: dual simplex + column perturbation 58
#      - dual_pertv72: dual simplex + column and row perturbation 72
#      - dual_pesteep_pertv58: dual automatic steepest + perturbation 58
#      - dual_pesteep_psi1_pertv61: dual automatic steepest + positive-edge psi 1.0 + perturbation 61
#      - dual_pesteep_psineg1_pertv61: dual automatic steepest + psi -1.0 + perturbation 61
#      - dual_pesteep_scaling_off: dual automatic steepest + scaling off
#      - primal_idiot10: primal simplex + 10 idiot-crash passes
#      - primal_idiot30: primal simplex + 30 idiot-crash passes
#      - primal_idiot50: primal simplex + 50 idiot-crash passes
#      - primal_idiot60: primal simplex + 60 idiot-crash passes
#      - primal_idiot500: primal simplex + 500 idiot-crash passes
#      - primal_sprint: primal simplex + sprint crash
#   2) CLI defaults (automatic crash choices and perturbation 50):
#      - dual_cli_default: baseline dual simplex
#      - primal_default: baseline primal simplex
#   3) Racing portfolio (-lpMethod racing / ClpRacingSolver):
#      - dual_pertv72 (shared with recommendation)
#      - racing_primal_idiot50, racing_primal_sprint (inherit perturbation 50)
#   4) Barrier methods (-lpMethod barrier):
#      - barrier_native: native Cholesky factorization
#      - barrier_dense: dense Cholesky factorization
#      - barrier_univ: UniversityOfFlorida (CHOLMOD + AMD + Woodbury dense-column update)

# Recommendation overrides are explicit: parseLpParamTag() defaults to
# psi=0, perturbation=100, idiot=0 and sprint=0. Its "pesteep" tags install
# ClpDualRowSteepest(3), not the CLI's PEsteepest pivot; only positive PSI
# subsequently wraps that pivot with positive-edge pricing.
# Racing's primal methods inherit CLI perturbation=50 instead of 100.

# ── Baselines ──────────────────────────────────────────────────────────
dual_cli_default|-lpMethod dual
primal_default|-lpMethod primal

# ── Dual simplex portfolio variants (from CbcLpParamScorer) ───────────
dual_default|-psi 0 -pertValue 100 -idiot 0 -sprint 0 -lpMethod dual
dual_pertv58|-psi 0 -pertValue 58 -idiot 0 -sprint 0 -lpMethod dual
dual_pertv72|-psi 0 -pertValue 72 -idiot 0 -sprint 0 -lpMethod dual
dual_pesteep_pertv58|-dualPivot automatic -psi 0 -pertValue 58 -idiot 0 -sprint 0 -lpMethod dual
dual_pesteep_psi1_pertv61|-dualPivot automatic -psi 1.0 -pertValue 61 -idiot 0 -sprint 0 -lpMethod dual
dual_pesteep_psineg1_pertv61|-dualPivot automatic -psi -1.0 -pertValue 61 -idiot 0 -sprint 0 -lpMethod dual
dual_pesteep_scaling_off|-dualPivot automatic -psi 0 -pertValue 100 -scaling off -idiot 0 -sprint 0 -lpMethod dual

# ── Primal simplex + idiot crash variants (from CbcLpParamScorer) ─────
primal_idiot10|-psi 0 -pertValue 100 -idiot 10 -sprint 0 -lpMethod primal
primal_idiot30|-psi 0 -pertValue 100 -idiot 30 -sprint 0 -lpMethod primal
primal_idiot50|-psi 0 -pertValue 100 -idiot 50 -sprint 0 -lpMethod primal
primal_idiot60|-psi 0 -pertValue 100 -idiot 60 -sprint 0 -lpMethod primal
primal_idiot500|-psi 0 -pertValue 100 -idiot 500 -sprint 0 -lpMethod primal

# ── Primal + sprint (from CbcLpParamScorer) ───────────────────────────
primal_sprint|-psi 0 -pertValue 100 -idiot 0 -sprint -1 -lpMethod primal

# ── Racing primal variants (from ClpRacingSolver) ───────────────────
racing_primal_idiot50|-pertValue 50 -idiot 50 -sprint 0 -lpMethod primal
racing_primal_sprint|-pertValue 50 -idiot 0 -sprint -1 -lpMethod primal

# ── Barrier methods (with OpenBLAS, LAPACK, SuiteSparse AMD/CHOLMOD) ──
barrier_native|-cholesky native -lpMethod barrier
barrier_dense|-cholesky dense -lpMethod barrier
barrier_univ|-cholesky Uni -lpMethod barrier
